# Telegram Expense Tracker

Личный трекер расходов. Записал трату одной строкой в чат — и всё, бот сам разложил её по категориям, посчитал итоги и может отдать отчёт. Сделал для себя: в приложениях для финансов то реклама, то регистрация, то «подключите банк». А так — просто пишешь в Telegram, и база в SQLite рядом.

## Команды

| Команда | Что делает |
|---|---|
| `/add 500 кофе` | записать расход: сумма + примечание, категория определится сама |
| `/today` | итого за сегодня |
| `/week` | итого за 7 дней |
| `/month` | итого за текущий месяц |
| `/report` | разбивка по категориям с долями |
| `/recent` | последние 10 записей |
| `/export` | CSV-файл за месяц (открывается в Excel без крякозябр) |

## Про автокатегоризацию

Никакого ML — чистая функция `parse_expense` + словарь ключевых слов в `categories.py`:

- «500 кофе», «250 капучино» → Еда и кафе;
- «2000 метро», «1000 такси» → Транспорт;
- «15000 айфон» → Покупки;
- не распозналось → «Разное».

Сумма понимает и запятую («49,99»), есть защита от опечаток (лимит суммы — чтобы «5000000» случайно не ушло в базу). Вся логика — чистые функции, покрытые unit-тестами без Telegram и БД.

## Почему CSV именно utf-8-sig

Обычный UTF-8 в CSV — это Excel открывает кириллицу как «ÐÑÐ¸Ð²ÐµÑ». BOM (`utf-8-sig`) — и всё читается. Мелочь, а нервы экономит.

## Запуск

```bash
python -m venv .venv
pip install -r requirements.txt
export EXPENSE_BOT_TOKEN=123456:ABC...   # токен от @BotFather
python bot.py
```

На Windows — `run_bot8.cmd` (токен из корневого `.env`). База по умолчанию — `expenses.db` рядом с ботом, путь можно переопределить через `EXPENSE_DB_PATH`.

## Из чего состоит

```
bot.py          — команды, отчёты, экспорт
categories.py   — парсинг строки и автокатегоризация (чистые функции)
db.py           — aiosqlite: записи, агрегаты GROUP BY / BETWEEN, индекс (user_id, created_at)
middlewares.py  — троттлинг и логирование
config.py       — настройки из переменных окружения
tests/          — 8 тестов (парсинг суммы с запятой, категории, агрегаты, CSV)
```
