# Telegram Expense Tracker

[![CI](https://github.com/d3c0r1x/telegram-expense-tracker/actions/workflows/ci.yml/badge.svg)](https://github.com/d3c0r1x/telegram-expense-tracker/actions/workflows/ci.yml)

Личный трекер расходов. Расход записывается одной строкой в чат; бот автоматически распределяет его по категориям, рассчитывает итоги и формирует отчёты. Данные хранятся в локальной базе данных SQLite рядом с ботом.

## Команды

| Команда | Назначение |
|---|---|
| `/add 500 кофе` | записать расход: сумма + примечание, категория определяется автоматически |
| `/today` | итого за сегодня |
| `/week` | итого за 7 дней |
| `/month` | итого за текущий месяц |
| `/report` | разбивка по категориям с долями |
| `/recent` | последние 10 записей |
| `/undo` | отменить последнюю запись (при опечатке) |
| `/export` | CSV-файл за месяц (корректно открывается в Excel) |

## Автокатегоризация

Без применения ML — чистая функция `parse_expense` + словарь ключевых слов в `categories.py`:

- «500 кофе», «250 капучино» → Еда и кафе;
- «2000 метро», «1000 такси» → Транспорт;
- «15000 айфон» → Покупки;
- не распознано → «Разное».

Сумма поддерживает десятичную запятую («49,99»); предусмотрена защита от ошибок ввода (лимит суммы, исключающий случайное сохранение значений вида «5000000»). Вся логика реализована чистыми функциями, покрытыми unit-тестами без Telegram и БД.

## Кодировка CSV: utf-8-sig

Без BOM Microsoft Excel некорректно отображает кириллицу в UTF-8 CSV. Использование `utf-8-sig` (с BOM) обеспечивает корректное отображение при минимальной разнице в реализации.

## Запуск

```bash
python -m venv .venv
pip install -r requirements.txt
export EXPENSE_BOT_TOKEN=123456:ABC...   # токен от @BotFather
python bot.py
```

На Windows — `start.bat` (токен из корневого `.env`). База по умолчанию — `expenses.db` рядом с ботом; путь переопределяется через `EXPENSE_DB_PATH`.

## Структура проекта

```
bot.py          — команды, отчёты, экспорт
categories.py   — парсинг строки и автокатегоризация (чистые функции)
db.py           — aiosqlite: записи, агрегаты GROUP BY / BETWEEN, индекс (user_id, created_at)
middlewares.py  — троттлинг и логирование
config.py       — настройки из переменных окружения
tests/          — 9 тестов (парсинг суммы с запятой, категории, агрегаты, CSV, undo)
```

## Планы развития

- бюджеты по категориям с предупреждением о превышении лимита;
- месячный отчёт в PDF (интеграция с проектом PDF-отчётов);
- экспорт за произвольный период, не только за месяц.
